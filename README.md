# Kamran Nissar – Portfolio
Static site: `index.html` + `images/`.

## Put it on GitHub (free hosting)
1. Create a new public repo named `kamran-portfolio` on github.com.
2. Click "Add file" > "Upload files", drag in `index.html`, `README.md` and the `images` folder, then Commit.
3. Go to Settings > Pages > Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`, Save.
4. After about a minute your site is live at `https://YOUR-USERNAME.github.io/kamran-portfolio/`.
